# Requerimientos No Funcionales — Dulce Diva

Los requerimientos no funcionales establecen las características de calidad, seguridad, rendimiento y funcionamiento que debe cumplir el sistema web Dulce Diva.

## RNF01 — Seguridad

El sistema debe proteger la información de los clientes mediante mecanismos de autenticación y control de acceso.

## RNF02 — Protección de contraseñas

Las contraseñas de los usuarios deben almacenarse utilizando algoritmos de hashing seguros y no en texto plano.

## RNF03 — Privacidad

El sistema debe proteger los datos personales proporcionados por los clientes y permitir su tratamiento de acuerdo con las políticas de protección de datos aplicables.

## RNF04 — Rendimiento

El sistema debe responder a las solicitudes de los usuarios en un tiempo adecuado para proporcionar una experiencia fluida.

## RNF05 — Disponibilidad

El sistema debe estar disponible para los usuarios durante los horarios establecidos para la atención y operación de Dulce Diva.

## RNF06 — Usabilidad

La interfaz debe ser sencilla, clara e intuitiva para facilitar la navegación de los clientes.

## RNF07 — Compatibilidad

El sistema debe funcionar correctamente en los principales navegadores web actuales.

## RNF08 — Diseño adaptable

La página web debe adaptarse correctamente a diferentes tamaños de pantalla, incluyendo computadores, tabletas y teléfonos móviles.

## RNF09 — Mantenibilidad

El código fuente debe estar organizado y estructurado para facilitar futuras modificaciones, correcciones y actualizaciones.

## RNF10 — Escalabilidad

El sistema debe permitir incorporar nuevos productos, usuarios y funcionalidades sin requerir modificaciones importantes en su estructura.

## RNF11 — Integridad de la información

El sistema debe garantizar que la información almacenada en la base de datos sea consistente y no se pierda durante las operaciones normales.

## RNF12 — Copias de seguridad

La información almacenada en la base de datos debe contar con mecanismos de respaldo que permitan recuperarla ante posibles fallos.

## RNF13 — Accesibilidad

La interfaz debe utilizar textos, botones y elementos visuales claros que faciliten su utilización por diferentes tipos de usuarios.

## RNF14 — Escalabilidad del chatbot

El chatbot debe permitir la incorporación y actualización de preguntas y respuestas para mejorar la atención al cliente.

## RNF15 — Tiempo de respuesta

Las funciones principales del sistema, como inicio de sesión, consulta de productos y registro de información, deben procesarse sin demoras excesivas.
