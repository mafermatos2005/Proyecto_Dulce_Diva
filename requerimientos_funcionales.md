RF01 — Registro de clientes

El sistema debe permitir que los clientes creen una cuenta proporcionando sus datos personales requeridos.

RF02 — Inicio de sesión

El sistema debe permitir a los clientes iniciar sesión mediante su correo electrónico y contraseña.

RF03 — Gestión de datos del cliente

El sistema debe permitir al cliente consultar y actualizar sus datos personales.

RF04 — Visualización de productos

El sistema debe permitir a los clientes consultar el catálogo de marquesas disponibles.

RF05 — Información de productos

El sistema debe mostrar información de cada producto, incluyendo nombre, sabor, descripción, precio e imagen.

RF06 — Selección de productos

El sistema debe permitir al cliente seleccionar los productos que desea adquirir.

RF07 — Realización de pedidos

El sistema debe permitir al cliente realizar un pedido indicando los productos, cantidades y datos necesarios para la entrega.

RF08 — Consulta del pedido

El sistema debe permitir al cliente consultar la información y el estado de sus pedidos.

RF09 — Atención mediante chatbot

El sistema debe proporcionar un chatbot para responder preguntas frecuentes y brindar atención básica a los clientes.

RF10 — Contacto con Dulce Diva

El sistema debe proporcionar un medio de contacto para que los clientes puedan comunicarse con la empresa.

RF11 — Gestión de productos

El administrador debe poder agregar, modificar y eliminar productos del catálogo.

RF12 — Gestión de pedidos

El administrador debe poder consultar y actualizar el estado de los pedidos realizados por los clientes.

RF13 — Gestión de clientes

El administrador debe poder consultar y administrar la información necesaria de los clientes registrados.

RF14 — Reportes

El sistema debe permitir generar reportes relacionados con la atención al cliente, incluyendo cantidad de personas atendidas, calificaciones y sugerencias.

RF15 — Recuperación de contraseña

El sistema debe permitir al cliente recuperar el acceso a su cuenta mediante un mecanismo de recuperación de contraseña.
